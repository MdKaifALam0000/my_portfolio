# My Portfolio

A modern, full-stack personal portfolio built with the MERN stack (MongoDB, Express, React, Node.js).

## Project Structure
- **/frontend**: React application built with Vite and Tailwind CSS.
- **/backend**: Express server and MongoDB database models.

## How to Run

1. Open two terminals via your code editor.
2. In the first terminal, run `cd backend` then `npm run dev`.
3. In the second terminal, run `cd frontend` then `npm run dev`.
